# Signalen achter de voordeur – prototype versie 3

Online meldformulier (prototype) uit het afstudeeronderzoek bij Eigen Haard.
Er worden **geen gegevens verstuurd of opgeslagen**: alles gebeurt alleen in de browser.

Starten op je eigen computer: `npm start` en open http://localhost:3000
Online: via Railway (de startopdracht `npm start` wordt automatisch gebruikt).
